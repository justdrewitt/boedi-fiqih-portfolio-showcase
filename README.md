# Portfolio Showcase with Contentful CMS

[English](#english) | [Indonesian](#indonesian)

## English

### Overview
This is a modern portfolio showcase website built with React, TypeScript, and Contentful CMS. The project utilizes Vite as the build tool and incorporates various modern web development practices and libraries.

### Features
- 🚀 Built with Vite + React + TypeScript
- 🎨 Styled with Tailwind CSS and Shadcn UI components
- 📱 Fully responsive design
- 🔍 SEO optimized
- 📝 Content management through Contentful CMS
- 🎭 Dark/Light mode support
- 📊 Rich text content rendering
- 🔄 Real-time content updates
- 🎯 Modern UI components with Radix UI
- 📱 Mobile-first approach

### Tech Stack
- **Frontend Framework**: React 18
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn UI, Radix UI
- **CMS**: Contentful
- **State Management**: React Query
- **Form Handling**: React Hook Form
- **Routing**: React Router
- **Animation**: Framer Motion
- **Deployment**: Vercel

### Getting Started

#### Prerequisites
- Node.js (v16 or higher)
- npm or yarn
- Contentful account and space

#### Installation
1. Clone the repository:
```bash
git clone [your-repository-url]
cd boedi-fiqih-portfolio-showcase
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Create a `.env` file in the root directory and add your Contentful credentials:
```env
VITE_CONTENTFUL_SPACE_ID=your_space_id
VITE_CONTENTFUL_ACCESS_TOKEN=your_access_token
VITE_CONTENTFUL_PREVIEW_ACCESS_TOKEN=your_preview_token
```

4. Start the development server:
```bash
npm run dev
# or
yarn dev
```

2. Define your content models
3. Add your content
4. Configure the environment variables with your Contentful credentials
